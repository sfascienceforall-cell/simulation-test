Longueur d’onde ou période ?

Une même onde vue de deux façons : la photo de la corde donne la longueur d’onde λ, le film d’un seul point donne la période T.

λ est une période dans l’espace : la distance entre deux crêtes, mesurée sur une photo (en m). T est une période dans le temps : la durée d’une oscillation d’un point, mesurée avec un chronomètre (en s). Le lien : λ = v · T (pendant une période, l’onde avance d’une longueur d’onde).
