Lancer vertical : le signe de g suit l’axe

Depuis un balcon, une personne lance une balle vers le haut. La trace stroboscopique et les graphiques y(t), v(t), a(t) se dessinent en même temps. Retourne l’axe y ou déplace l’origine : tous les signes changent, mais pas le mouvement. Ajoute l’air pour voir apparaître la vitesse limite.

Axe y
Origine O
v₀  vitesse de lancer
h  hauteur de lancer
Air
Astuce : touche l’axe y pour le retourner ; attrape le balcon pour le monter ou le descendre ; tire la pointe de la flèche verte v₀ ; glisse sur les graphiques pour avancer ou reculer dans le temps.
